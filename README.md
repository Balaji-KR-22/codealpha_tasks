# CodeAlpha Projects

A collection of full-stack web development projects demonstrating practical skills in frontend development, backend engineering, database management, authentication, and real-time collaboration.

## Projects

### 1. E-commerce Website

A web-based shopping platform that enables users to browse products, manage shopping carts, and handle online shopping workflows.

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MySQL

**Directory:** `ecommerce-website`

---

### 2. Connect Social

A social networking application designed to help users connect, share content, and interact through a web-based platform.

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MySQL

**Directory:** `connect-social`

---

### 3. TaskFlow Pro

A collaborative project management platform that helps teams organize projects, assign tasks, track progress, and communicate efficiently.

**Key Features:**
- Project and task management
- Team member assignments
- Task comments and discussions
- Priorities and deadlines
- Notifications and activity tracking
- Real-time collaboration

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MySQL, Socket.IO

**Directory:** `taskflow-pro`

---

### 4. ConnectSphere

A real-time communication and collaboration platform designed for virtual meetings, team discussions, and interactive teamwork.

**Key Features:**
- User authentication and account management
- Multi-user video conferencing
- Screen sharing
- File sharing
- Collaborative whiteboard
- Real-time messaging
- Meeting room management
- Secure communication and access control

**Technologies:** HTML, CSS, JavaScript, Node.js, Express.js, MySQL, WebRTC, Socket.IO

**Directory:** `connectsphere`

---
